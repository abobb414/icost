# Icost

DeepSeek-powered automatic bookkeeping shortcut for Apple Shortcuts.

The public shortcut contains no API key. After importing it, replace
`YOUR_DEEPSEEK_API_KEY` in the `Authorization` header with your own DeepSeek
API key before running it.

The request uses the current `deepseek-v4-flash` model and the official
`https://api.deepseek.com/chat/completions` endpoint.
